SeekDrop

Follow SoundCloud channels and playlists. When a track shows up, SeekDrop looks for it on Soulseek and downloads the best copy it can find.

  1. Before you start

    SeekDrop searches Soulseek, a network where people share their own music folders. You decide what you download and share. Only download music you have the right to have, such as free downloads, promos sent to you, or tracks you've bought. You're responsible for how you use it.

  2. Connect to Soulseek

    SeekDrop adds a small plugin to Nicotine+ so the two apps can talk. It only works on this computer.

    Use a separate account just for SeekDrop. A name that doesn't exist yet is created automatically when you log in. Logging in with the same account in another Soulseek app will disconnect one of them.

  3. Where tracks go

    Many people on Soulseek only let you download if you share something too. Sharing means others can download these files from you.

    File checks

    Quality

    Replacing an MP3 with a FLAC changes the file name, so Rekordbox or Serato lose the cue points of the old file. The old file goes to SeekDrop's trash for 30 days.

    Rekordbox

    In Rekordbox choose File, Export Collection in xml format, and pick that file here. SeekDrop only reads it, to see which tracks are in Rekordbox. With the upgrade setting above, those tracks are never replaced by themselves, because a new file name loses their cue points. Export again now and then. Without this file SeekDrop asks first for every track.

    Every finished download becomes a track, and each channel or playlist becomes a playlist inside a folder called SeekDrop. In Rekordbox: Preferences, Advanced, Database, tick rekordbox xml and choose this file. Then open rekordbox xml in the tree, right-click a playlist and choose Import Playlist. SeekDrop only writes this one file and never touches Rekordbox' own library. A track that is replaced by a better copy gets a new file name, so Rekordbox sees it as a new track.

    Soulseek etiquette

    Soulseek is run by volunteers. Searching slowly and not filling your disk keeps you from being blocked.

    Blocked after repeated problems. Blocks end by themselves after 30 days.
